### Invoice Ingestion & Approval Automation

**Status:** Completed working POC

This project demonstrates an end-to-end invoice ingestion and approval workflow built using Microsoft Power Automate, Outlook and SharePoint.

**Workflow:**  
Outlook email → Power Automate trigger → Attachment retrieval → SharePoint file storage → Invoice Register record creation → Approval routing → Approve/Reject decision → SharePoint status update

**Tools used:**  
Microsoft Power Automate, SharePoint, Outlook, Microsoft 365

**Capabilities demonstrated:**
- Email-triggered workflow automation
- Invoice ingestion
- Attachment handling
- SharePoint integration
- Structured record creation
- Approval routing
- Conditional logic
- Approved / Rejected status updates
- Approval date capture
- Reviewer comments
- Testing and validation
- Trigger filtering to prevent recursive approval emails

**Business value:**  
The workflow reduces manual invoice handling by automatically capturing incoming invoices, storing supporting documents, creating a structured record and routing the invoice for approval. It improves consistency, visibility and control while providing a clear audit trail.
